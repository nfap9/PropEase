```typescript
function buildOrganizationSlug(name: string) {
  return (
    name
      .toLowerCase()
      .replace(/\s+/g, '-')
      .replace(/[^a-z0-9-]/g, '') || 'org'
  );
}
```

2. useState for isReady
3. useEffect for auth check + redirect logic:

   - If no orgs (organizations.length === 0) → setIsReady(true) (show creation form)
   - If has orgs → auto-select via getPostAuthRedirectPath, if path !== '/organizations' redirect
   - Otherwise setIsReady(true)

5. useMutation for createOrgMutation:
   - mutationFn: organizationsApi.create with slug built from name

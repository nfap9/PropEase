## Layout Patterns

**Organization Page (`/organizations`):**
- Centered card layout (max-w-lg) for both empty state and selection list
- Single page dual entry: empty state (0 orgs) or card list (multiple orgs)
- Form container uses same card pattern as existing `/organizations/new`

**Settings Organization Switch:**
- Inline display: current org name + "切换" button
- Uses existing settings page card grid pattern (Phase 1)

**Navigation Flow:**
- Auto-redirect on auto-selection (no UI confirmation)
- Manual selection: click card → set org → toast → redirect to dashboard

## Interaction States

| State | Visual Treatment |
|-------|-----------------|

| Loading | Skeleton or disabled button with spinner |
| Error | Red text message below relevant field, retry button for load failures |

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(0 0% 100%)` / `hsl(222.2 84% 4.9%)` (dark mode) | Background, surfaces |
| Secondary (30%) | `hsl(210 40% 96.1%)` | Cards, sidebar, nav |
| Accent (10%) | `hsl(221 83% 53%)` | **Active nav items only** |
| Destructive | `hsl(0 84.2% 60.2%)` | Destructive actions only |

**Accent reserved for:**
1. Active navigation link background (`bg-primary` in NavContent)
2. Primary button fills
3. Focus rings (`ring: hsl(221 83% 53%)`)
4. Form error borders

**Accent is NOT used for:** Card borders, dividers, inactive icons, or decorative elements.

**Pre-populated from:** `globals.css` CSS variables. Color split confirmed from existing CSS variable usage patterns (background=100%, card=100%, secondary/muted/accent=light gray, primary=blue accent).

## Layout Contract

### Auth Pages (Login/Register)

- Centered card on `bg-muted/40` background
- Card max-width: `max-w-md`
- Card contains: brand title, subtitle, form fields, submit button, footer link
- No sidebar, no header navigation
- Link to admin login: absolute positioned bottom-right corner

### Dashboard Layout (Authenticated)

- `h-screen` flex container
- **Sidebar (desktop):** `w-64` fixed left column, `bg-muted/40`, full height, contains `NavContent`
- **Main area:** `flex-1` flex column
  - **Header:** `h-16` fixed top, `border-b`, contains: mobile Sheet trigger (Menu icon, not Bell), OrgSelector (centered), ThemeToggle, notifications bell (with unread badge), user avatar dropdown
  - **Main content:** `flex-1 overflow-auto p-6` scrollable content area
- **Mobile Sheet:** `w-64` left drawer with `NavContent`

### Sidebar Collapse (New in Phase 4)

- Adopt shadcn/ui `sidebar.tsx` collapsible mode
- Expanded: icon + label visible
- Collapsed: icon only + tooltip on hover
- Transition: smooth width animation

### Known Bug (Must Fix)

- `MainLayout` line 76-78: Sheet trigger uses `<Bell>` icon instead of `<Menu>` for mobile navigation
- Must be changed to `<Menu>` before Phase 4 is considered complete

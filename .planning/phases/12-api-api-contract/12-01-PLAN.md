## Gap 2: ApartmentWithStats 定义分散

`api/src/repositories/apartment.repo.ts` 在本地定义了 `ApartmentWithStats` 和 `RoomStats`，但 `packages/api-contract/src/apartments.ts` 已导出相同定义。

**当前状态：**
- api-contract 导出: `ApartmentWithStats` (extends Apartment + room_stats), `RoomStats`
- repo 本地定义: `ApartmentWithStats` (extends Apartment + rooms + room_stats), `RoomStats`

**api-contract 的 ApartmentWithStats 结构（正确）：**
```typescript
// packages/api-contract/src/apartments.ts
export interface ApartmentWithStats extends Apartment {
  room_stats: RoomStats;
}
```

**repo 的本地定义：**
```typescript
// api/src/repositories/apartment.repo.ts
export type ApartmentWithStats = Apartment & {
  rooms: Room[];
  room_stats: RoomStats;
};
```

**修复方案：** 在 apartment.repo.ts 中，将 RoomStats 和 ApartmentWithStats 的本地定义删除（或保留 rooms 扩展），改为从 @apartment-ultra/api-contract 导入 RoomStats，同时保留 ApartmentWithStats 的本地 rooms 扩展（因为 api-contract 版本不含 rooms）。

## Gap 3: Prisma Decimal 序列化

Prisma Decimal 字段（land_area, total_area, landlord_rent, operating_cost）在 JSON 序列化后为字符串，而非 api-contract 定义的 number。

**受影响的 Decimal 字段：**
- `land_area` - Decimal(10,2)
- `total_area` - Decimal(10,2)
- `landlord_rent` - Decimal
- `operating_cost` - Decimal

**修复方案：** 在 apartment.service.ts 的 listByOrg 和 getById 返回前，将 Decimal 字段通过 Number() 或 parseFloat() 转换为 number。

在 apartment.service.ts 中，为 listByOrg 和 getById 添加 Decimal 序列化逻辑。

**需要转换的 Decimal 字段：** land_area, total_area, landlord_rent, operating_cost

在 createApartmentService 函数的 listByOrg 和 getById 返回前，将 Decimal 字段通过 Number() 转换为 number：

```typescript
listByOrg: async (orgId: string) => {
  const apartments = await getRepo().findByOrgIdWithRooms(orgId);
  return apartments.map((apt) => {
    const { land_area, total_area, landlord_rent, operating_cost, ...rest } = apt;
    return {
      ...rest,
      land_area: land_area != null ? Number(land_area) : null,
      total_area: total_area != null ? Number(total_area) : null,
      landlord_rent: landlord_rent != null ? Number(landlord_rent) : null,
      operating_cost: operating_cost != null ? Number(operating_cost) : null,
      room_stats: calculateRoomStats(apt.rooms),
    };
  });
},

getById: async (orgId: string, id: string) => {
  const apartment = await getRepo().findByIdAndOrgWithRooms(id, orgId);
  if (!apartment) {
    throw createAppError(404, NotFoundMessages.APARTMENT);
  }
  const { land_area, total_area, landlord_rent, operating_cost, ...rest } = apartment;
  return {
    ...rest,
    land_area: land_area != null ? Number(land_area) : null,
    total_area: total_area != null ? Number(total_area) : null,
    landlord_rent: landlord_rent != null ? Number(landlord_rent) : null,
    operating_cost: operating_cost != null ? Number(operating_cost) : null,
  };
},
```

这样确保 API 返回的 Decimal 字段为 number 类型，与 api-contract 定义一致。

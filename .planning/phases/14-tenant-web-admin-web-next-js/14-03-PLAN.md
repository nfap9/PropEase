2. Create `tenant-web/src/app/admin/layout.tsx`:

```tsx
import { AdminAuthLayout } from '@/components/layout/admin-auth-layout';

export default function AdminLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return <AdminAuthLayout>{children}</AdminAuthLayout>;
}
```

The AdminAuthLayout component:
- Checks for `admin_access_token` in localStorage
- Redirects to `/admin/login` if not present
- Wraps children in AdminLayout if authenticated
- Excludes `/admin/login` and `/admin/setup` from auth check

This ensures only admin users can access /admin/* routes (except login).

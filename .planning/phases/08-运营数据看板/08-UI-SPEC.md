## Layout Contract

### Page Structure

```
[Page Title: 平台概览]
[Refresh Button — top right, icon + text, variant: outline]
[Stat Cards Row — 6 cards in responsive grid (2/3/6 cols)]
  [公寓数] [房间数] [入住率%] [本月收入] [待缴账单] [逾期账单]
[Charts Row — 2 cards side by side]
  [收入趋势 Chart — left, 60% width]  [入住率分析 Chart — right, 40% width]
[Year Filter — above charts row]
```

### Grid Spec

- Stat cards: `grid-cols-2 lg:grid-cols-3 xl:grid-cols-6` (6 cols on xl, 3 on lg, 2 on sm)
- Charts row: `grid-cols-1 lg:grid-cols-5` — income chart spans 3 cols, occupancy spans 2 cols
- Card padding: p-6 (24px)
- Section gap: gap-6 (24px)

### Responsive Strategy

- Mobile: single column, charts stack vertically
- Tablet: 2-col stat grid, charts stack
- Desktop: 6-col stat grid, side-by-side charts

## Component Inventory

### StatCard (existing, reused)
- Uses `Card` + `CardHeader` + `CardContent` from shared-ui
- Title: 14px medium muted-foreground
- Value: 28px bold foreground
- Hover: subtle shadow (shadow-sm)
- Format: occupancy as percentage (1 decimal), revenue as currency (2 decimals, thousand-separator)

### ChartCard (new)
- Wrapper around `Card` with `CardHeader` + `CardContent`
- Title in CardHeader (20px semibold)
- Chart fills CardContent
- Consistent height: h-[320px]

### IncomeChart (new, recharts)
- Type: ComposedChart (Bar + Line)
- Bars: collected_amount (chart-1), uncollected (chart-3)
- Line: collection_rate (chart-2)
- X-axis: period (month labels)
- Tooltip: custom with month + amounts + rate
- Responsive container

### OccupancyChart (new, recharts)
- Type: AreaChart
- Area: occupancy_rate (chart-2)
- Reference line at 80% (warning threshold)
- X-axis: period (month labels)
- Y-axis: 0-100%
- Tooltip: custom with month + rate + room counts

### RefreshButton (new)
- Position: top-right of page title row
- Style: variant=outline, size=sm
- Icon: RefreshCw (lucide-react), animated spin during loading
- Label: 刷新数据

### YearFilter (new)
- Type: Select dropdown (shared-ui Select component)
- Options: current year - 2 through current year + 1
- Default: current year
- Position: left of chart cards row, aligned with chart titles

## Interaction Contracts

### Data Loading
- On mount: fetch overview + income + occupancy in parallel
- Show skeleton placeholders matching card dimensions during load
- All 3 queries must succeed to render charts
- If any fails: show error state, keep stat cards visible

### Refresh (DASH-04)
- Button triggers invalidate + refetch of all 3 queries
- Spinner icon on button during refetch
- No modal or confirmation — immediate refetch

### Chart Hover
- Tooltip shows exact values for hovered month
- Tooltip disappears on mouse leave

### Year Filter
- Changing year refetches income + occupancy data
- Charts animate transition between years (recharts default)

## Spacing Scale

Declared values (multiples of 4, Tailwind default):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, compact gaps (`gap-1`) |
| sm | 8px | Default element gap (`gap-2`) |
| md | 16px | Section padding (`p-4`, `mb-4`) |
| lg | 24px | Card padding (`p-6`), section spacing |
| xl | 32px | Major section gaps |
| 2xl | 48px | Page-level spacing (`max-w-2xl` margin) |
| 3xl | 64px | Not typically used |

Exceptions: none — follow Tailwind default scale.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` — 0 0% 100% | Page background |
| Secondary (30%) | `hsl(var(--card))` — 0 0% 100% | Cards, panel backgrounds |
| Accent (10%) | `hsl(var(--accent))` — 210 40% 96.1% | Hover states, subtle highlights |
| Primary | `hsl(var(--primary))` — 221 83% 53% | Buttons, links, focus rings |
| Destructive | `hsl(var(--destructive))` — 0 84.2% 60.2% | Delete actions only |
| Success | `hsl(var(--success))` — 142 71% 45% | Active status badge |
| Warning | `hsl(var(--warning))` — 38 92% 50% | Warning states |

Accent reserved for:
- Select dropdown hover backgrounds
- Table row hover states
- Sidebar active item backgrounds

**Source:** globals.css CSS variable definitions

## Page Structure

### Organization List Page (`/organizations`)
**Existing page — no structural changes for Phase 9 list features.**

| Element | Implementation |
|---------|---------------|
| Container | `mx-auto max-w-6xl` |
| Header row | Flex, `justify-between`, `mb-4` |
| Heading | `<h2>` `text-xl font-semibold` |
| Filter | Select component, `w-36` |
| Table | DataTable component with ColumnDef |

### Organization Detail Page (`/organizations/[id]`)
**Enhanced in Phase 9 — adds member management + resource stats.**

| Element | Implementation |
|---------|---------------|
| Container | `mx-auto max-w-2xl` |
| Back button | `Button variant="ghost" size="icon"` + ArrowLeft icon |
| Page heading | `<h2>` `text-xl font-semibold` |
| Info card | Card + CardHeader + CardContent + CardTitle |
| Member section | Card below info card |
| Action area | Below CardContent, `pt-4` |

### Create/Edit Organization Dialog
**New component for Phase 9.**

| Element | Implementation |
|---------|---------------|
| Trigger | Primary Button ("新建组织" / "编辑") |
| Container | Dialog component (shared-ui) |
| Width | `max-w-md` |
| Fields | Input for name, Textarea for notes |
| Slug display | Read-only text showing auto-generated slug |
| Actions | Cancel (secondary) + Submit (primary) |

### Delete Organization Dialog
**New component for Phase 9.**

| Element | Implementation |
|---------|---------------|
| Container | AlertDialog component (shared-ui) |
| Warning content | Organization name, resource statistics from deletion-preview |
| Actions | Cancel + "停用组织" (destructive variant) or "删除组织" (destructive) |

### Member Management Panel (within detail page or Sheet)
**New component for Phase 9.**

| Element | Implementation |
|---------|---------------|
| Add member | Button + Dialog with phone Input + Role Select |
| Member list | Table component with avatar, phone, role badge, joined date |
| Role badge | Badge with variant by role (owner=default, admin=secondary, member=outline, viewer=muted) |
| Actions per row | DropdownMenu — Change Role / Transfer Owner / Remove |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (list page) | 新建组织 |
| Primary CTA (detail page) | 添加成员 |

# Requirements: Apartment Ultra

**Defined:** 2026-03-20
**Core Value:** 高效的公寓管理体验 — 让房东和租客都能直观地完成日常操作

## v1.1 Requirements (运营后台)

### 运营数据看板

- [ ] **DASH-01**: 运营人员可查看全局统计数据（公寓数、房间数、入住率）
- [ ] **DASH-02**: 运营人员可查看收入趋势（按月/按年）
- [ ] **DASH-03**: 运营人员可查看入住率分析
- [ ] **DASH-04**: 运营数据支持刷新

### 组织和成员管理

- [ ] **ORGM-01**: 平台管理员可创建/编辑/删除组织
- [ ] **ORGM-02**: 平台管理员可查看组织列表
- [ ] **ORGM-03**: 平台管理员可管理组织成员（添加/移除/角色分配）

### 系统配置

- [ ] **SYSC-01**: 平台管理员可配置费用模板（水价、电价、管理费）
- [ ] **SYSC-02**: 平台管理员可配置通知方式

### 默认角色配置

- [ ] **ROLE-01**: 平台管理员可配置租户端的默认角色及权限

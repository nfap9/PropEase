# 功能描述

实现一个可商用的公寓管理系统应用，目标用户是承包公寓进行运营收租的管理者（二房东）。

## 核心需求

### 公寓管理系统（用户端）

#### 用户登录、注册

- 用户注册：用户可使用手机号注册，必须需要填写手机号、用户名、密码（二次确认）
- 用户登录：注册成功后可使用手机号+密码登录，也可以用手机号+验证码登录；

#### 组织

- 创建组织：用户创建组织后才能使用，登录后如果没有组织则进入组织创建页面
- 组织切换：用户如果有组织则进入最近使用的组织，也可通过用户菜单栏中的组织切换菜单进入组织切换页面；
- 邀请成员：用户可以通过手机号、邀请链接添加其他用户加入组织；
- 权限控制：用户通过角色来控制成员权限，可以维护角色、给成员配置角色

#### 公寓

- 公寓新增编辑：公寓可记录公寓信息（名称、位置、楼层数、占地面积、总面积、上游信息），上游信息包括：房东姓名、联系方式、合同期、租金，已经可以记录经营公寓的各项花费；
- 公寓删除：公寓中的房间全都没有租约时可以删除公寓；
- 房间管理：每个公寓可以创建多个房间（查看房间段落）
- 水电单价管理：每个公寓可维护水电费单价；在选择房间签约时默认带出公寓维护水电单价；

#### 房间

- 添加房间：公寓中可以单个添加房间(一次填写房间所有信息添加)、也可以批量添加房间(选择楼层范围、每层房间数量自动生成房间号，经过再次确认后生成房间；批量生产房间时只生产房间号)；
- 编辑房间：可以编辑房间的信息；
- 删除房间：删除必须二次确认，有履行中的租约的房间不能删除，有历史租约的房间删除时需要提醒用户；
- 房间列表：实现一个查询房间功能，根据房间的各种信息进行筛选、搜索，房间列表上要有签约、编辑、删除、查看操作按钮；
- 房间详情：查看房间打开房间详情；可以查看房间的所有信息、可以查找所有租约；

#### 费用项目

- 组织级费用项目：可以维护（增删查改）组织级费用项目（管理费、卫生费、网费），根据类型、规格两级管理，使用树形表格实现；

#### 租约

- 创建租约：用户选择房间、填写租客信息、填写房租、水电单价、押金、租期、租赁周期、出账日、费用项目等信息后创建租约；

- 编辑租约；不能直接编辑租约信息，提供对租约的固定操作：换房（更换房间），续约（延长租期），编辑费用项目，房租变更（可配置从哪个账期开始生效），编辑租客信息；

- 退租结算：租客到期退租、违约终止合同时要进行退租结算，录入一次水电记录后计算房租水电账单，根据押金进行多退少补；可选择是否违约，违约时押金不退；

#### 水电费用账单

- 新的租约必须录入一次初始水电，需要在水电录入页面和首页提醒用户；

- 显示水电账单表格，要能区分已完成和未完成的水电账单，水电账单表格中每行显示一个房间的一个周期的水电账单，包含房间、账期、上月水电读数、本月水电读数、水电单价、水电费，状态；未完成的水电账单可以在表格操作列中填写水电记录；根据到出账日的距离排序；临近出账日或已超期的要在首页提醒用户；

- 批量导入水电记录，可批量导出即将到出账日的房间记录表，用户填写完后导入完成记录。

#### 房租账单

- 账单查看：实现一个账单列表

- 首期账单：租约创建后自动生成首期账单，包括房租、押金、和配置的其他项目；

- 月租账单：到出账日的房间会自动生成账单，如果到出账日用户没有登记该账期的水电表读数则出账失败；房租账单包括房租、水电账单、其他费用；

- 可批量导出月租账单（PDF、Excel）。

- 确认收款：记录账单状态，用户可标记账单是否收款、收款方式，可部分收款。

#### 信息统计和事务提醒

事务提醒:
- 水电录入提醒：待录入水电房间、预期未录入房间
- 账单提醒：未收款账单、出账失败账单、部分收款账单；
信息统计：
- 空房一览
- 本月收支统计
- 房间状态统计
- 年度收支统计

### 运营系统（运营端）

- 独立的账号系统：运营系统账号和用户端不互通；

- 系统初始化：系统初始化时只有一个系统管理员，拥有运营系统的所有权限。

- 管理运营角色：运营系统分角色管理权限；

- 管理运营账号：添加、删除、启用/停用、修改账号角色、重置密码。

- 付费服务：组织的数量、公寓数量、房间数量、团队成员数量需要付费使用；当前使用运营人员手动配置实现；用户系统外支付，运营收款后手动给用户账号配置额度、时长；

## 改造策略

### 当前方案

由于前端可能尚未添加 `data-testid`，采用以下策略：

1. **添加 TODO 注释**：在所有使用文案定位的地方添加 `TODO` 注释，说明前端添加对应 `data-testid` 后可替换
2. **保持测试通过**：当前测试仍能正常运行，不影响现有测试执行
3. **渐进式改造**：后续可根据前端添加 `data-testid` 的进度，逐步替换

### 最终目标

- ✅ 所有测试代码已添加 `import { ... } from './testids'`
- ✅ 所有测试使用文案定位的地方已标注 `TODO`
- 🔄 前端代码需要逐步添加 `data-testid` 属性
- 🔄 测试代码逐步替换为 `page.getByTestId(...)`

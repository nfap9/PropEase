# SaaS 订阅优惠系统测试用例

## 测试环境
- 后端开发环境
- 数据库已同步最新 Schema
- 测试账号已登录

## 测试范围

### 1. 优惠活动类型测试

#### 1.1 噪折扣优惠
- 创建一个折扣率优惠活动（如 8 折）
- 创建一个减免金额优惠活动（如减 100 元）
- 验证购买时价格计算正确

#### 1.2 鷷梯优惠
- 创建阶梯优惠活动
  - 购买 3 个月：9 折
  - 购买 6 个月：85 折
  - 购买 12 个月：8 折
- 验证不同购买月数的折扣正确应用

#### 1.3 优惠券
- 创建优惠券活动，- 使用优惠码验证
- 验证使用次数限制
- 验证最低金额限制

#### 1.4 推荐奖励
- 创建推荐活动
- 生成推荐码
- 使用推荐码购买
- 验证推荐人和被推荐人双方都获得奖励

#### 1.5 系统赠送
- 创建系统赠送活动
- 执行系统赠送
- 验证用户余额增加

### 2. 优惠叠加测试

#### 2.1 不可叠加优惠
- 创建两个不可叠加优惠
- 验证只能使用一个

#### 2.2 可叠加优惠
- 创建可叠加优惠
- 验证多个优惠同时应用

#### 2.3 优先级测试
- 创建不同优先级的优惠
- 验证按优先级顺序应用

### 3. API 接口测试

#### 3.1 优惠码验证接口
- POST /subscriptions/validate-coupon
- 测试有效优惠码
- 测试无效优惠码
- 测试过期优惠码

- 测试已用完优惠码

#### 3.2 可用优惠列表接口
- GET /subscriptions/organizations/:org_id/available-promotions
- 验证返回可用优惠

#### 3.3 价格计算接口
- POST /subscriptions/calculate-price
- 测试不使用优惠
- 测试使用优惠码
- 测试使用余额
- 测试使用推荐码
- 测试组合使用

#### 3.4 推荐码接口
- GET /subscriptions/referrals/my-code
- 验证返回推荐码

#### 3.5 余额接口
- GET /subscriptions/organizations/:org_id/balance
- 验证返回余额信息

#### 3.6 订单创建接口（增强版）
- POST /subscriptions/organizations/:org_id/orders
- 测试创建不带优惠的订单
- 测试创建带优惠码的订单
- 测试创建带余额抵扣的订单
- 测试创建带推荐码的订单

- 测试创建带多个优惠的订单

### 4. 前端页面测试

#### 4.1 购买页面
- 验证优惠码输入框正常显示
- 验证余额抵扣开关正常显示
- 验证推荐码输入框（首次购买时）正常显示
- 验证价格明细正确显示
- 验证优惠验证反馈正确显示

#### 4.2 确认弹窗
- 验证优惠信息正确显示
- 验证价格计算正确
- 验证创建订单正确

### 5. 支付流程测试

#### 5.1 模拟支付
- 使用模拟支付完成订单
- 验证优惠正确应用
- 验证推荐奖励正确发放
- 验证余额正确扣减

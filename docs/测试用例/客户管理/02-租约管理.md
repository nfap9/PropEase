# 租约管理模块测试用例

## 租约列表页

### 入口
进入公寓管理系统 - 点击左侧「租约管理」菜单 - 右侧页面显示租约列表页

### 路由
`/leases`

---

### 功能 1：租约列表

测试用例：查看租约列表
前置条件：当前登录账号所选组织下有租约
测试步骤：进入租约管理页面 - 查看页面展示
预期结果：页面显示租约列表表格，包含：房间、租客、开始日期、结束日期、月租、状态

测试用例：显示已有的测试租约
前置条件：已通过 API 或其他方式创建过测试租约
测试步骤：进入租约管理页面 - 查看列表
预期结果：列表中显示已创建的测试租约

---

### 功能 2：租约筛选

测试用例：按状态筛选租约
前置条件：存在不同状态的租约
测试步骤：进入租约管理页面 - 选择状态筛选（进行中/已结束）- 观察列表变化
预期结果：列表只显示所选状态的租约

测试用例：按公寓筛选
前置条件：存在多个公寓的租约
测试步骤：进入租约管理页面 - 选择公寓 - 观察列表变化
预期结果：列表只显示所选公寓下的租约

测试用例：按日期范围筛选
前置条件：存在租约
测试步骤：进入租约管理页面 - 选择开始日期范围 - 观察列表变化
预期结果：列表只显示开始日期在范围内的租约

---

### 功能 3：新增租约

测试用例：显示创建租约弹窗
前置条件：无
测试步骤：进入租约管理页面 - 点击「新增租约」按钮
预期结果：创建租约弹窗出现

测试用例：成功创建租约
前置条件：存在空置房间、存在租客
测试步骤：进入租约管理页面 - 点击「新增租约」按钮 - 选择公寓、房间、租客 - 填写开始日期、月租、押金 - 点击「确认」
预期结果：租约创建成功，房间状态变为已租

测试用例：选择已出租房间显示错误
前置条件：存在已出租房间
测试步骤：进入租约管理页面 - 点击「新增租约」按钮 - 尝试选择已出租的房间
预期结果：已出租房间不可选择或显示错误提示

测试用例：租客为空显示验证错误
前置条件：无
测试步骤：进入租约管理页面 - 点击「新增租约」按钮 - 选择房间 - 不选择租客 - 点击「确认」
预期结果：显示租客必选的错误提示

---

### 功能 4：签约时选择额外费用

测试用例：签约时可选择额外费用
前置条件：公寓已配置费用项
测试步骤：创建租约 - 在额外费用区域选择费用类型和规格
预期结果：可以选择额外费用，租约创建后费用项关联到租约

测试用例：同一费用类型只能选择一个规格
前置条件：公寓已配置费用项
测试步骤：创建租约 - 选择某个费用类型的规格 A - 尝试再选择同一费用类型的规格 B
预期结果：只能选择一个规格，选择 B 后 A 自动取消

---

### 功能 5：编辑租约

测试用例：编辑租约信息
前置条件：存在租约
测试步骤：进入租约管理页面 - 找到目标租约 - 点击「编辑」按钮 - 修改信息 - 点击「保存」
预期结果：编辑弹窗出现，修改后保存成功，租约信息更新

---

### 功能 6：终止租约

测试用例：显示终止租约弹窗
前置条件：存在进行中的租约
测试步骤：进入租约管理页面 - 找到进行中的租约 - 点击「终止」按钮
预期结果：终止确认弹窗出现

测试用例：成功终止租约
前置条件：存在进行中的租约
测试步骤：进入租约管理页面 - 找到进行中的租约 - 点击「终止」按钮 - 确认终止
预期结果：租约终止成功，房间状态变为空置

---

### 功能 7：删除租约

测试用例：删除租约
前置条件：存在租约
测试步骤：进入租约管理页面 - 找到目标租约 - 点击「删除」按钮 - 确认删除
预期结果：弹出确认对话框，确认后租约被删除

# 房间管理模块测试用例

## 全部房间页

### 入口
进入公寓管理系统 - 点击左侧「全部房间」菜单 - 右侧页面显示全部房间页

### 路由
`/rooms`

> **重要说明**：此页面仅用于查看和管理所有公寓的房间，**不支持新增、编辑、删除房间**。新增、编辑、删除房间功能均在「公寓详情页」。此页面主要用于查看房间、搜索筛选、签约。

---

### 功能 1：房间列表
测试用例：查看房间列表
前置条件：当前登录账号所选组织下有房间
测试步骤：进入全部房间页面 - 查看页面展示
预期结果：页面显示房间统计卡片（总房间数、已出租、空置、维修中）和房间列表表格，表格包含：房间号、所属公寓、户型、面积、月租、状态、备注
测试用例：显示已有的测试房间
前置条件：已通过 API 或其他方式创建过测试房间
测试步骤：进入全部房间页面 - 查看列表
预期结果：列表中显示已创建的测试房间
---
### 功能 2：房间搜索
测试用例：搜索房间号
前置条件：存在房间
测试步骤：进入全部房间页面 - 在搜索框输入房间号关键字 - 观察列表变化
预期结果：列表只显示房间号包含关键字的房间
测试用例：搜索备注
前置条件：存在有备注的房间
测试步骤：进入全部房间页面 - 在搜索框输入备注关键字 - 观察列表变化
预期结果：列表只显示备注包含关键字的房间
---
### 功能 3：房间筛选
测试用例：按公寓筛选房间
前置条件：存在多个公寓
测试步骤：进入全部房间页面 - 展开筛选 - 选择某个公寓 - 观察列表变化
预期结果：列表只显示所选公寓下的房间
测试用例：按状态筛选房间
前置条件：存在不同状态的房间
测试步骤：进入全部房间页面 - 展开筛选 - 选择状态（空置/已租/维修中）- 观察列表变化
预期结果：列表只显示所选状态的房间
测试用例：按户型筛选房间
前置条件：存在不同户型的房间
测试步骤：进入全部房间页面 - 展开筛选 - 选择户型 - 观察列表变化
预期结果：列表只显示所选户型的房间
测试用例：按月租范围筛选
前置条件：存在房间
测试步骤：进入全部房间页面 - 展开筛选 - 输入最低月租和最高月租 - 观察列表变化
预期结果：列表只显示月租在范围内的房间
测试用例：按面积范围筛选
前置条件：存在房间
测试步骤：进入全部房间页面 - 展开筛选 - 输入最小面积和最大面积 - 观察列表变化
预期结果：列表只显示面积在范围内的房间
测试用例：清除筛选
前置条件：已设置筛选条件
测试步骤：点击「清除筛选」按钮
预期结果：所有筛选条件被清除，列表显示所有房间
---
### 功能 4：签约
测试用例：为空置房间签约
前置条件：存在空置房间、存在租客
测试步骤：进入全部房间页面 - 找到空置房间 - 点击「签约」按钮 - 填写租约信息 - 保存
预期结果：租约创建成功，房间状态变为已租
---
### 功能 5：退租
测试用例：为已出租房间退租
前置条件：存在已出租且有活跃租约的房间
测试步骤：进入全部房间页面 - 找到已出租房间 - 点击「退租」按钮 - 确认退租
预期结果：租约终止，房间状态变为空置
---
### 功能 6：更改状态
测试用例：更改房间状态
前置条件：存在房间
测试步骤：进入全部房间页面 - 找到房间 - 点击「更多操作」- 选择新状态
预期结果：房间状态更新成功
---

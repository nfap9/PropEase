# 测试用例目录

本目录存放面向业务验收的测试用例文档。

## 作用

- 帮助产品、测试、开发对齐“功能应该怎样工作”
- 为 E2E 编写提供业务场景清单
- 在功能重构后作为回归检查入口

## 子目录说明

- `通用/`
  作用：跨模块公共能力，如导航、经营分析等。
- `认证/`
  作用：登录、注册与身份相关流程。
- `房源管理/`
  作用：公寓、房间等基础资源管理。
- `客户管理/`
  作用：租客、租约等客户与合同主流程。
- `财务管理/`
  作用：水电、账单、费用配置。
- `系统设置/`
  作用：组织、权限、通知、订阅等系统层能力。
- `运营后台/`
  作用：平台侧运营管理能力。

## 当前维护约定

- 这些文档描述“业务预期”，不等于 API 文档。
- 如果页面路由、按钮名称或功能入口变了，应优先更新这里。
- 如果某份文档对应的功能已经废弃，应明确标注“已废弃”，而不是继续保留为现行说明。

## 与 E2E 的关系

- 文档中的场景不要求与 E2E 文件一一对应。
- 但高频主流程最好能在 E2E 中找到覆盖。
- 文档中引用 E2E 文件时，应确保路径真实存在。

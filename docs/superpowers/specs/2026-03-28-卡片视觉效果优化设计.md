# 卡片视觉效果优化设计

## 背景

前端现有组件大量使用圆角边框+阴影实现卡片视觉效果，视觉上过于厚重。本次优化目标是精简视觉效果，保留必要的信息区分能力。

## 设计原则

1. **统计卡片**：保持现有卡片效果（圆角+边框+阴影），作为数据聚焦的视觉锚点
2. **信息卡片**：用分隔线区分信息区块，保留适度圆角但去除阴影
3. **表格/列表容器**：去除卡片包装，仅保留表格结构
4. **分页器**：去除卡片包装，样式简洁化
5. **表单区域**：去除卡片包装，字段间用分隔线区分

## 组件变更详情

### 1. 信息卡片（详情页）

**变更范围**：房间详情、租客详情、公寓详情等详情页中的信息展示区域

**变更前**：
```tsx
<Card>
  <CardHeader>...</CardHeader>
  <CardContent>...</CardContent>
</Card>
```

**变更后**：使用分隔线替代卡片包装
```tsx
<div className="space-y-4">
  <div className="flex justify-between items-center pb-4 border-b">
    <span className="text-sm text-muted-foreground">房间号</span>
    <span className="font-medium">101</span>
  </div>
  <div className="flex justify-between items-center pb-4 border-b">
    <span className="text-sm text-muted-foreground">状态</span>
    <Badge>活跃</Badge>
  </div>
  ...
</div>
```

### 2. 表格容器

**变更范围**：admin-web 和 tenant-web 中的 DataTable 组件

**变更前**：
```tsx
<Card>
  <CardHeader>...</CardHeader>
  <CardContent>
    <DataTable ... />
  </CardContent>
</Card>
```

**变更后**：直接使用表格组件，无需卡片包装
```tsx
<div className="border rounded-lg">
  <DataTable ... />
</div>
```

### 3. 分页器

**变更范围**：DataTable 关联的分页器组件

**变更前**：
```tsx
<Card className="mt-4">
  <CardContent className="p-4">
    <Pagination>...</Pagination>
  </CardContent>
</Card>
```

**变更后**：简化包装
```tsx
<div className="flex items-center justify-between px-4 py-3 border-t">
  <Pagination>...</Pagination>
</div>
```

### 4. 表单区域

**变更范围**：表单中的字段组、字段区块

**变更前**：
```tsx
<Card>
  <CardHeader>基本信息</CardHeader>
  <CardContent className="space-y-4">
    <FormField ... />
    <FormField ... />
  </CardContent>
</Card>
```

**变更后**：使用分隔线区分字段组
```tsx
<div className="space-y-6">
  <div>
    <h3 className="text-sm font-medium mb-4">基本信息</h3>
    <div className="space-y-4">
      <FormField ... />
      <FormField ... />
    </div>
  </div>
  <div className="border-t pt-6">
    <h3 className="text-sm font-medium mb-4">其他信息</h3>
    ...
  </div>
</div>
```

## 技术实现要点

1. **共享 Card 组件**：保留 shared-ui 中的 Card 组件不变，供统计卡片使用
2. **信息展示模式**：在详情页中采用 key-value 分组布局，使用 `border-b` 分隔
3. **表格简化**：DataTable 外层仅保留必要的 `border rounded-lg`，不额外使用 Card 包装
4. **分页器独立**：分页器作为独立行，去掉卡片包装，样式与表格融为一体
5. **表单分组**：用 `border-t` 分隔不同字段组，组标题使用 `h3` 或自定义标题组件

## 涉及文件

- `packages/shared-ui/src/components/ui/card.tsx` — 保留不变
- `tenant-web/src/components/common/data-table.tsx` — 表格容器简化
- `admin-web/src/components/common/data-table.tsx` — 表格容器简化
- `tenant-web/src/app/apartments/[id]/page.tsx` — 信息卡片改造
- 其他详情页（租客、账单等）— 信息卡片改造
- 各模块中的表单页面 — 表单分组改造

## 验收标准

1. 统计卡片视觉保持不变
2. 信息详情页使用分隔线区分，视觉更扁平
3. 表格外层无多余卡片包装
4. 分页器简洁化
5. 表单区域使用分隔线区分字段组

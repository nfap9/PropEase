## 汇总与建议

- **已修复项**
  1. **认证**：`POST /auth/login` 已增加 `user.is_active` 校验，停用用户返回 401（AUTH-L-05）。
  2. **通用**：已支持 header `x-org-id` 传递当前组织；缺组织时 400 文案为「需要选择组织」；v1 未匹配路径已通过 catch-all 返回 404（GEN-04）。
- **可选增强**
  - 运营统计：`GET /admin/stats` 增加公寓数等指标。  
  - 权限：组织角色权限接口从占位改为真实读写权限数据。  
  - 自定义角色：若产品上希望「管理员/财务/运营」不可删，可将初始化时的 `is_system` 设为 `true`。

以上排查基于当前 api 代码与测试用例文档的对照，未执行前端或 E2E；实际联调时请以接口契约与用例预期为准再核对一次。

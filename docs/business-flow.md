## 一、核心业务链路

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           初始化阶段                                     │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │

│                                                                         │
```

## 二、初始化配置流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 注册账号 | 手机号 + 密码 |
| 2 | 创建组织 | 多租户隔离，每个用户可管理多个组织；创建者自动成为**组织所有者** |
| 3 | 创建公寓 | 组织下可创建多个公寓 |
| 4 | 添加房间 | 公寓下添加房间，设置房间号/面积/楼层 |
| 5 | 配置费用项 | 组织下配置本组织可用的费用项（水、电、租金、管理费等） |

---

## 三、日常运营流程

| 步骤 | 操作 | 触发时机 | 说明 |
|------|------|----------|------|
| 6 | 创建租约 | 租客入住 | 关联房间与租客，从组织费用项中选择本租约适用的费用 |
| 7 | 录入水电 | 每月固定日期 | 记录水表/电表读数，系统自动计算水电费 |
| 8 | 生成账单 | 每月 | 系统根据租约费用项 + 水电读数计算本期账单 |
| 9 | 收款核销 | 租客付款 | 记录收款金额/方式/日期 |

## 四、费用项体系

### 4.1 费用项分类

| 分类 | 说明 | 周期选项 | 计费方式 |
|------|------|---------|---------|
| `fixed` 固定费用 | 租金、管理费等 | monthly/quarterly/yearly/one_time | 按固定金额 |
| `utility` 用量费用 | 水费、电费 | monthly | 按读数 × 单价 |
| `optional` 可选费用 | 押金、卫生费等 | monthly/one_time | 按固定金额 |

### 4.2 业务费用项说明

| 费用项 | 分类 | 周期 | 计费方式 | 备注 |
|--------|------|------|---------|------|
| 租金 | fixed | monthly | 固定月租金 | |
| 水费 | utility | monthly | (本期读数 - 上期读数) × 单价 | |
| 电费 | utility | monthly | (本期读数 - 上期读数) × 单价 | |
| 管理费 | fixed | monthly | 固定金额 | |
| 卫生费 | fixed | monthly | 固定金额 | |
| 网费 | fixed | monthly | 固定金额 | |
| 清运费 | optional | one_time | 固定金额 | 部分地区要求收取 |
| 退房卫生费 | optional | one_time | 固定金额 | 仅退租时收取 |
| 钥匙押金 | optional | one_time | 固定金额 | 退租时可退还 |
| 押金 | fixed | one_time | 月租金 × N | 仅首期账单收取 |

### 4.3 费用项配置层级

```
Organization (组织)
  └── Apartment (公寓)
          ├── ApartmentConfig (公寓配置)
          │       ├── 水电单价配置
          │       └── ApartmentFeeItem (公寓费用项)
          │               ├── 公寓级别：定义本公寓有哪些费用项及其默认值
          │               └── LeaseFeeItem (租约费用项)
          │                       └── 租约级别：关联到具体租约，金额可个性化
          │                               └── BillFeeItem (账单费用项)
          │                                       └── 账单级别：本期实际产生的费用
          └── Room (房间)
```

**设计说明：**
- `ApartmentFeeItem` 是模板，每个公寓独立管理自己的费用项列表
- 支持将某公寓的配置（水电单价+费用项）复制/应用到其他公寓
- `LeaseFeeItem` 是租约创建时从公寓模板中选择/关联的实例
- 同一模板在不同租约中金额可以不同（如不同房间定价不同）
- 账单生成时从 `LeaseFeeItem` 读取，生成 `BillFeeItem`

## 五、账单金额计算逻辑

### 5.1 账单总金额公式

```
账单总金额 = 租金 + 押金（仅首期）+ 水费 + 电费 + 其他固定费用 + 可选费用
```

### 5.2 水电费计算

```
水费 = (本期水表读数 - 上期水表读数) × 水费单价
电费 = (本期电表读数 - 上期电表读数) × 电费单价
```

### 5.3 首期账单示例

假设：月租金 ¥2,000，押金 2 个月，水价 ¥5/吨（本期 120，上期 50），电价 ¥1/度（本期 350，上期 100）

| 费用项 | 计算方式 | 金额 |
|--------|----------|------|
| 租金 | 固定月租金 | ¥2,000 |
| 押金 | 月租金 × 2 | ¥4,000 |
| 水费 | (120 - 50) × 5 | ¥350 |
| 电费 | (350 - 100) × 1 | ¥250 |
| **首期合计** | | **¥6,600** |

### 5.4 续期账单示例（无押金）

| 费用项 | 计算方式 | 金额 |
|--------|----------|------|
| 租金 | 固定月租金 | ¥2,000 |
| 水费 | (170 - 120) × 5 | ¥250 |
| 电费 | (450 - 350) × 1 | ¥100 |
| **月租合计** | | **¥2,350** |

## 六、角色权限体系

### 6.1 角色分类

组织内角色分为**预制角色**和**自定义角色**：

| 角色 | 类型 | 说明 |
|------|------|------|
| 组织所有者 | 预制（is_system=true） | 创建组织时自动成为，拥有全部权限 |
| 公寓管理人 | 预制（is_system=true） | 除 settings 外拥有所有权限 |
| 一般合伙人 | 预制（is_system=true） | 仅 view + export 权限 |
| 自定义角色 | 用户创建 | 组织所有者自行定义 |

### 6.2 权限码体系

权限采用 `资源:操作` 格式，如 `apartment:create`

**资源模块：** apartment / room / tenant / lease / bill / utility / member / settings / report

**操作类型：** view / create / edit / delete / export

### 6.3 预制角色权限详情

| 权限 | 组织所有者 | 公寓管理人 | 一般合伙人 |
|------|:---------:|:---------:|:---------:|
| settings 模块 | ✅ 全部 | ❌ | ❌ |
| 其他 8 个模块全部操作 | ✅ 全部 | ✅ 全部 | 仅 view/export |

- 组织所有者：9模块 × 5操作 = **45 个权限码**
- 公寓管理人：8模块 × 5操作 = **40 个权限码**
- 一般合伙人：8模块 × 2操作 = **16 个权限码**

### 6.4 角色与数据隔离

- 组织所有者 = Organization 的创建者，自动成为该组织的成员
- 任意成员只能访问其所属 Organization 的数据
- 不同 Organization 之间数据完全隔离

## 七、状态机

### 7.1 房间状态（Room.status）

```
available（可用）
      │
      ├──[创建租约]──→ occupied（已出租）
      │                      │
      │                      ├──[租约到期/退租]──→ available
      │                      │
      │                      └──[设为维护]──→ maintenance
      │
      └──[设为维护]──→ maintenance（维护中）
                              │
                              └──[维护完成]──→ available
```

### 7.2 租约状态（Lease.status）

```
active（进行中）
    │
    ├──[租约到期]──→ ended（已结束）
    │
    └──[提前退租]──→ terminated（已终止）
```

### 7.3 账单状态（Bill.status）

```
pending（待支付）
    │
    ├──[部分收款]──→ partial（部分支付）
    │
    ├──[全额收款]──→ paid（已支付）
    │
    ├──[逾期]──→ overdue（已逾期）
    │
    └──[红冲调整]──→ reversed（已冲销，仅供追溯，不可修改）
```

### 7.4 支付记录状态（Payment.status）

```
pending（待确认）
    │
    ├──[确认到账]──→ paid（已支付）
    │
    └──[退款]──→ refunded（已退款）
```

### 7.5 订阅状态（OrganizationSubscription.status）

```
active（生效中）
    │
    ├──[到期未续费]──→ expired（已过期）
    │
    └──[主动取消]──→ cancelled（已取消）
```

## 八、通知体系

### 8.1 站内通知范围

站内通知当前仅面向房东侧（组织所有者 + 公寓管理人）。

详细规则见 `notification-spec.md`。

**通知类型一览：**

| 类型码 | 名称 | 触发 |
|--------|------|------|
| `bill_generated` | 账单已生成 | 事件触发 |
| `rent_due_reminder` | 交租日提醒 | 定时（每日08:03，提前3/2/1天） |
| `bill_overdue` | 账单逾期 | 定时（每日08:05） |
| `payment_received` | 收款到账 | 事件触发 |
| `lease_expiring` | 租约即将到期 | 定时（每日08:00，提前7/3/1天） |
| `lease_ended` | 租约已结束 | 事件触发 |
| `utility_reading_abnormal` | 水电读数异常 | 事件触发 |

> ⚠️ 租客端（小程序/服务号）后续开发

## 九、异常流程

### 9.1 提前退租

租客主动提前结束租约：

| 处理项 | 规则 |
|--------|------|
| 押金 | **不退** |
| 最后一期账单 | 正常计算（水电费等） |
| 租约状态 | → terminated |
| 房间状态 | → available（退房后） |

### 9.2 水电表读数异常

本期读数 < 上期读数（换表/抄表错误）：

- **处理方式：** 标记异常，暂停自动计算，等人工介入处理
- 人工确认读数后，按实际值计算

### 9.3 账单调整（红冲+新出）

当已出账单存在计算错误或遗漏时，采用红冲+新出方式处理。

**前提条件：** 原账单状态为 `pending`（待支付）或 `partial`（部分支付）

**操作流程：**

```
Step 1: 原账单状态改为 `reversed`，记录 reversed_by_id → 关联红字账单
Step 2: 生成「红字账单」（金额为负），状态 `paid`，内容与原账单一致
Step 3: 生成「新账单」（正确金额），替代原账单
```

**字段变更：**

| 字段 | 说明 |
|------|------|
| 原账单.status | → `reversed` |
| 原账单.reversed_by_id | → 关联红字账单ID |
| 红字账单.status | → `paid` |
| 红字账单.reverses_id | → 关联原账单ID |
| 新账单.status | → `pending` |
| 新账单.adjusts_id | → 关联原账单ID（可选，便于追溯） |

**特殊情况：**

| 场景 | 处理方式 |
|------|---------|
| 原账单已全额付款 | 红字账单金额为负，新账单金额为正，余额退至租客账户或结转下期 |
| 原账单已部分付款 | 超出已付金额部分生成补收账单 |
| 涉及水电用量重算 | 新账单重新读取水电读数 |

**已冲销账单不可修改，不可删除，仅供追溯。**

### 9.4 超期占用（租约到期未退房）

| 场景 | 处理方式 |
|------|---------|
| 双方均未提出退租 | **自动续期**（按原月租金，自动延一个月） |
| 到期前已提出退租 | **按天计费**（实际占用天数 × 日租金） |

> 日租金 = 月租金 ÷ 30

### 9.5 钥匙押金退还

退租时钥匙完好 → **全额退还**
钥匙损坏/丢失 → 按约定扣除或全额不退（规则可由组织自定义）

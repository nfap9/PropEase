# Apartment Ultra 业务流程梳理

## 一、核心业务链路

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           初始化阶段                                     │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   注册账号 ──→ 创建组织 ──→ 创建公寓 ──→ 添加房间 ──→ 配置价格           │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                           运营阶段（循环）                               │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   创建租约 ──→ 录入水电 ──→ 生成账单 ──→ 收款核销                       │
│       │                                                    ▲            │
│       │                                                    │            │
│       └────────────────────────────────────────────────────┘            │
│                         (每月循环)                                       │
└─────────────────────────────────────────────────────────────────────────┘
```

## 二、详细流程说明

### 阶段一：初始化配置

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 注册账号 | 手机号 + 密码 |
| 2 | 创建组织 | 多租户隔离，每个用户可管理多个组织 |
| 3 | 创建公寓 | 组织下可创建多个公寓 |
| 4 | 添加房间 | 公寓下添加房间，设置房间号/面积/楼层 |
| 5 | 配置价格 | 设置月租金、水费基准、电费基准 |

### 阶段二：日常运营

| 步骤 | 操作 | 触发时机 | 说明 |
|------|------|----------|------|
| 6 | 创建租约 | 租客入住 | 关联房间与租客，设置租金/押金/租期 |
| 7 | 录入水电 | 每月固定日期 | 记录水表/电表读数 |
| 8 | 生成账单 | 每月 | 系统自动计算各项费用 |
| 9 | 收款核销 | 租客付款 | 记录收款金额/方式/日期 |

## 三、账单金额计算逻辑

```
账单总金额 = 租金 + 押金（仅首期）+ 水费 + 电费 + 其他费用

水费 = (本期水表读数 - 上期水表读数) × 水费单价
电费 = (本期电表读数 - 上期电表读数) × 电费单价
```

### 示例（首期账单）

| 费用项 | 计算方式 | 金额 |
|--------|----------|------|
| 租金 | 固定月租金 | ¥2,000 |
| 押金 | 月租金 × 2 | ¥4,000 |
| 水费 | (120 - 50) × 5 | ¥350 |
| 电费 | (350 - 100) × 1 | ¥250 |
| **合计** | | **¥6,600** |

## 四、租约生命周期

```
可用(Vacant) ──[创建租约]──→ 已出租(Occupied) ──[租约到期/退租]──→ 可用(Vacant)
                              │
                              ▼
                        维护中(Maintenance) ──[维修完成]──→ 可用(Vacant)
```

---

## 五、账单状态流转

```
待支付(Pending) ──[部分收款]──→ 部分支付(Partial)
      │
      │──[全额收款]──→ 已支付(Paid)
      │
      │──[逾期]──→ 已逾期(Overdue)
```


## 七、关键业务规则

1. **账单去重**：同一月份已生成账单不会重复生成
2. **押金只在首期**：只有第一期账单包含押金
3. **租约状态联动**：创建租约后房间状态自动变为「已出租」
4. **费用项独立存储**：租金/押金在 Bill 表，水电费在 BillFeeItem 表
5. **支付方式灵活**：支持现金/微信/支付宝/银行转账等

# 功能描述

实现一个可商用的公寓管理系统应用，目标用户是承包公寓进行运营收租的管理者（二房东）。

## 核心需求

### 公寓管理系统

#### 用户/组织

- 用户可创建组织，组织的数量、公寓数量、房间数量、团队成员数量受付费等级控制；付费等级可在运营系统中配置。
- 可以将组织数据迁移到另一个组织中。
- 用户可以创建、编辑组织；删除组织是高危操作，需在组织无订阅且用户严格二次确认后才能删除。
- 创建组织的用户为组织所有人，可以邀请其他用户加入组织，可以转让组织所有人；组织所有人拥有组织内部所有权限。
- 组织内部可以进行角色管理；初始预置有管理员角色和运营人员角色，组织所有人可以新增、删除、编辑角色和角色权限。

#### 公寓

- 每个组织可以添加多个公寓，可记录公寓信息。
- 每个公寓中有多个房间，可维护房间信息（批量添加、删除、编辑等）。
- 每个公寓可维护水电费单价、网费（不同规格）、管理费、服务费等公用费用，方便后续签约记账时使用。

#### 租约

- 可管理租客和租约；每个租约需包含租客信息、房间信息、合同信息（租期、租赁方式：日租、月租、年租）。
- 可终止租约、启用租约。

#### 水电账单

- 可记录水电表读数，按月记录；可批量导出即将到出账日的房间记录表，用户填写完后导入完成记录。
- 到出账日的房间会自动生成账单，可批量导出账单（PDF、Excel）。
- 可记录账单状态（是否支付、是否逾期等）。

#### 信息统计和事务提醒

- 能够统计到期房间、未支付账单等用户关注的事务。
- 能够统计房间数量、空房数量、住户人数等数据。
- 能够分析运营数据、总房租、支出、利润等。

### 运营系统（产品运营人员使用）

- 要有独立的账号系统；系统初始化时只有一个系统管理员，拥有运营系统的所有权限。
- 可以管理运营角色：初始有一个管理员角色，不可编辑删除，拥有所有运营系统权限；管理员可以新增、删除、编辑角色和管理角色权限。
- 能够管理运营账号：添加、删除、启用/停用、修改账号角色、重置密码。
- 能够配置订阅套餐、费用定价，组织状态管理（仅支持启用、停用），运营分析。

#### 套餐/定价/额度

- 运营系统可以配置各种套餐定价策略。
- 每个套餐可维护允许的组织数、公寓数量、房间数量、成员数量。
- 可配置房间数、成员数的计算方式（用户下的总数量还是单个组织下的总数量）。

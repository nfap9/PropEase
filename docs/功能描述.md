# 功能描述

本文档描述一套可商用的公寓管理系统，目标用户为承包公寓进行运营收租的管理者（即"二房东"）。

---

## 一、公寓管理系统（业务端）

### 1.1 用户认证

| 功能 | 说明 |
|------|------|
| 注册 | 使用手机号注册，必填项：手机号、用户名、密码（需二次确认） |
| 登录 | 支持两种方式：手机号 + 密码、手机号 + 验证码 |
| 登录后 | 进入所属组织的公寓管理系统 |

### 1.2 组织管理

#### 1.2.1 基本操作

- **创建组织**：填写组织名称、组织类型（合伙人/企业/个体经营）、备注
- **编辑组织**：修改组织名称、组织类型、备注
- **删除组织**：高危操作，仅在组织无订阅且用户二次确认后方可执行
- **数据迁移**：支持将组织内的公寓数据迁移至其他组织

#### 1.2.2 成员与权限

- **组织所有人**：创建组织的用户默认为所有人，可邀请成员加入、转让所有权，拥有组织内全部权限
- **角色管理**：系统预置「管理员」和「运营人员」两种角色；组织所有人可新增、编辑、删除角色及其权限

### 1.3 公寓管理

#### 1.3.1 公寓信息

| 字段 | 说明 |
|------|------|
| 基本信息 | 名称、位置、楼层数、占地面积、总面积 |
| 上游信息 | 房东姓名、联系方式、合同期、租金 |
| 经营成本 | 记录经营公寓的各项花费 |

#### 1.3.2 费用配置

- **水电费单价**：每个公寓可独立维护，签约时自动带出
- **其他费用**：网费（多规格可选）、管理费、服务费等，签约时可选择添加

### 1.4 房间管理

| 操作 | 说明 |
|------|------|
| 单个添加 | 维护房间完整信息（房间号、户型、面积、设施） |
| 批量添加 | 选择楼层范围、每层房间数，自动生成房间号；生成后需二次确认 |
| 编辑 | 修改房间信息 |
| 删除 | 需二次确认；履行中的租约不可删除，有历史租约时需提醒用户 |
| 查询筛选 | 根据多维度信息筛选，列表提供签约、编辑、删除、查看等操作入口 |
| 房间详情 | 查看房间全部信息及所有关联租约 |

**房间信息字段**：房间号、户型、面积、设施（家具家电）

### 1.5 租约管理

- **租约组成**：租客信息 + 房间信息 + 合同信息（租期、租赁方式）
- **租赁方式**：支持日租、月租、年租
- **租约状态**：支持终止、启用操作

### 1.6 水电账单

#### 1.6.1 水电录入

- 新租约**必须**录入初始水电读数，系统会在水电录入页面提醒
- 按月记录水电表读数
- 显示待录入房间列表，根据距离出账日天数以不同颜色标识
- 支持批量导出待录入房间表，填写后导入完成记录

#### 1.6.2 账单生成

- 出账日自动生成账单，支持批量导出（PDF/Excel）
- 未录入水电会导致出账失败，系统会提醒用户先完成录入
- 记录账单状态（已支付/未支付/逾期等）

### 1.7 统计与提醒

| 类别 | 功能 |
|------|------|
| 事务提醒 | 录入水电提醒、出账提醒、收账提醒 |
| 业务统计 | 到期房间、未支付账单、房间数量、空房数、住户人数 |
| 经营分析 | 运营数据、收入、支出、利润分析 |

## 二、运营系统（管理端）

运营系统供产品运营人员使用，与业务端账号体系相互独立。

### 2.1 账号与权限

| 功能 | 说明 |
|------|------|
| 初始账号 | 系统初始化时仅有一个系统管理员，拥有全部权限 |
| 角色管理 | 预置不可编辑删除的「管理员」角色；管理员可新增、编辑、删除角色及权限 |
| 账号管理 | 添加、删除、启用/停用账号；修改账号角色；重置密码 |

### 2.2 订阅与定价

- **组织管理**：支持启用、停用组织
- **套餐配置**：配置订阅套餐及费用定价
- **运营分析**：查看运营数据分析

### 2.3 套餐额度配置

每个套餐可配置以下额度：

| 额度项 | 说明 |
|--------|------|
| 组织数量 | 允许创建的组织上限 |
| 公寓数量 | 允许创建的公寓上限 |
| 房间数量 | 允许创建的房间上限 |
| 成员数量 | 允许添加的成员上限 |
| 计算方式 | 房间数、成员数按「用户下总数」或「单组织下总数」计算 |

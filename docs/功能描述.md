# 功能描述

实现一个可商用的公寓管理系统应用，目标用户是承包公寓进行运营收租的管理者（二房东）。

## 核心需求

### 公寓管理系统

#### 用户登录、注册

- 用户可使用手机号注册，必须需要填写手机号、用户名、密码（二次确认）
- 注册成功后可使用手机号+密码登录，也可以用手机号+验证码登录；
- 登录成功后进入公寓管理系统；

#### 组织

- 用户可创建组织，需要输入组织名称、组织类型（合伙人、企业、个体经营）、备注；
- 用户可以编辑组织，包括：组织名称、组织类型（合伙人、企业、个体经营）、备注；
- 可以删除组织，删除组织是高危操作，需在组织无订阅且用户严格二次确认后才能删除。
- 创建组织的用户为组织所有人，可以邀请其他用户加入组织，可以转让组织所有人；组织所有人拥有组织内部所有权限。
- 组织内部可以进行角色管理；初始系统预置有管理员角色和运营人员角色，组织所有人可以新增、删除、编辑角色和角色权限。
- 可以将组织中的公寓数据迁移到另一个组织中。

#### 公寓

- 组织中可以添加公寓，可记录公寓信息（名称、位置、楼层数、占地面积、总面积、上游信息），上游信息包括：房东姓名、联系方式、合同期、租金，已经可以记录经营公寓的各项花费；
- 每个公寓可以创建多个房间，可维护房间信息（批量添加、删除、编辑等）。房间信息包括房间号、户型、面积、设施（家具家电）；
- 每个公寓可维护水电费单价；在选择房间签约时默认带出公寓维护水电单价；
- 可以维护网费（不同规格）、管理费、服务费等费用项目，可以在签约时选择这些费用；

#### 房间

- 添加房间：公寓中可以单个添加房间、也可以批量添加房间，选择楼层范围、每层房间数量自动生成房间号，经过再次确认后生成房间；批量生产房间时只生产房间号；单独添加房间可以维护房间的所有信息；
- 编辑房间：可以编辑房间的信息；
- 删除房间：删除必须二次确认，有履行中的租约的房间不能删除，有历史租约的房间删除时需要提醒用户；
- 实现一个查询房间功能，根据房间的各种信息进行筛选、搜索，房间列表上要有签约、编辑、删除、查看操作按钮；
- 房间详情：查看房间打开房间详情；可以查看放假的所有信息、可以查找所有租约；

#### 租约

- 可管理租客和租约；每个租约需包含租客信息、房间信息、合同信息（租期、租赁方式：日租、月租、年租）。
- 可终止租约、启用租约。

#### 水电费用账单

- 新的租约必须录入一次初始水电，需要在水电录入页面提醒用户；
- 要显示月待录入水电的房间，根据日期距离显示不同颜色；
- 可记录水电表读数，按月记录；可批量导出即将到出账日的房间记录表，用户填写完后导入完成记录。
- 到出账日的房间会自动生成账单，可批量导出账单（PDF、Excel）。未录入水电会导致出账失败，需要提醒用户录入后再出账；
- 可记录账单状态（是否支付、是否逾期等）。

#### 信息统计和事务提醒
- 提醒用户录入水电、出账、收账；
- 能够统计到期房间、未支付账单等用户关注的事务。
- 能够统计房间数量、空房数量、住户人数等数据。
- 能够分析运营数据、收入、支出、利润等。

### 运营系统（产品运营人员使用）

- 要有独立的账号系统；系统初始化时只有一个系统管理员，拥有运营系统的所有权限。
- 可以管理运营角色：初始有一个管理员角色，不可编辑删除，拥有所有运营系统权限；管理员可以新增、删除、编辑角色和管理角色权限。
- 能够管理运营账号：添加、删除、启用/停用、修改账号角色、重置密码。
- 能够配置订阅套餐、费用定价，组织状态管理（仅支持启用、停用），运营分析。

#### 套餐/定价/额度

- 组织的数量、公寓数量、房间数量、团队成员数量受付费等级控制；付费等级可在运营系统中配置。
- 运营系统可以配置各种套餐定价策略。
- 每个套餐可维护允许的组织数、公寓数量、房间数量、成员数量。
- 可配置房间数、成员数的计算方式（用户下的总数量还是单个组织下的总数量）。

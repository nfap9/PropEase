# 项目计划文件夹

本文件夹存放所有项目开发计划文档。

## 命名规范

```
[优先级]-[主题]-plan.md
```

- **优先级**: `P0` | `P1` | `P2` | `ongoing`
- **主题**: 简短英文描述，使用 kebab-case

### 示例

```
P0-component-refactor-plan.md    # P0 优先级：组件重构计划
P1-ux-optimization-plan.md       # P1 优先级：交互优化计划
ongoing-api-design-plan.md       # 持续进行：API 设计计划
```

## 文档格式模板

所有计划文档必须包含以下结构：

```markdown
# [计划标题]

> 创建日期: YYYY-MM-DD
> 最后更新: YYYY-MM-DD
> 状态: ⬜ 未开始 | 🟡 进行中 | ✅ 已完成 | ⏸️ 暂停

## 📊 进度概览

**总进度: X/Y 任务完成 (Z%)**

| 阶段 | 状态 | 说明 |
|-----|------|------|
| 阶段1 | ⬜/🟡/✅ | 描述 |

## 背景

简述计划的背景和目标。

## 任务清单

### 阶段一：[阶段名称]

#### 1. ⬜ [任务标题]

**目标：** 简述目标

**步骤：**
- [ ] 步骤1
- [ ] 步骤2
- [ ] 步骤3

**验收标准：**
- [ ] 标准1
- [ ] 标准2

---

## 技术方案

（可选）详细技术实现方案。

## 风险与对策

| 风险 | 影响 | 对策 |
|-----|------|------|
| 风险1 | 高/中/低 | 对策1 |

## 更新日志

| 日期 | 变更内容 |
|-----|---------|
| YYYY-MM-DD | 初始创建 |
```

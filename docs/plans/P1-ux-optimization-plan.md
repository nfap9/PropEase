## 背景

### 当前问题

1. **功能割裂**: 公寓管理和房间管理完全分离，用户需要多个页面切换
2. **操作效率低**: 所有表格操作隐藏在下拉菜单，需要多次点击
3. **信息孤岛**: 各模块之间缺乏关联导航
4. **视觉一致性**: 仪表盘图标重复使用，缺乏辨识度

### 优化目标

- 提升操作效率，减少点击次数
- 增强功能连贯性，实现场景化工作流
- 改善视觉体验，提高信息辨识度

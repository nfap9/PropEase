# 站内通知规范

> 文档版本：v1.0 | 创建日期：2026-04-21

## 一、通知对象

**当前阶段：** 仅房东侧（组织所有者 + 公寓管理人）

> 租客端（小程序/服务号）后续开发，届时通知将同步支持租客侧

---

## 二、通知类型汇总

| 编号 | 类型码 | 名称 | 触发时机 | 发送对象 |
|------|--------|------|---------|---------|
| N1 | `bill_generated` | 账单已生成 | 每月账单生成后 | 组织所有者 / 公寓管理人 |
| N2 | `rent_due_reminder` | 交租日提醒 | 到期前 3/2/1 天 | 同上 |
| N3 | `bill_overdue` | 账单逾期 | 账单逾期后每日检查 | 同上 |
| N4 | `payment_received` | 收款到账 | 租客付款成功 | 同上 |
| N5 | `lease_expiring` | 租约即将到期 | 到期前 7/3/1 天 | 同上 |
| N6 | `lease_ended` | 租约已结束 | 租约到期或终止 | 同上 |
| N7 | `utility_reading_abnormal` | 水电读数异常 | 录入读数低于上期 | 同上 |

---

## 三、详细说明

### N1 账单已生成（bill_generated）

**触发时机：** 每月 1 日自动生成账单后，立即发送

**通知内容：**
```
标题：账单已生成 - {租客名}
内容：租客 {租客名}（房间 {房间号}）{年}/{月} 账单已生成，金额 ¥{总额}，请及时跟进。
```

**extra_data 字段：**
```json
{
  "category": "billing",
  "target_path": "/bills",
  "action_label": "查看账单",
  "bill_id": "...",
  "tenant_name": "...",
  "room_number": "...",
  "amount": 2300.00,
  "bill_year": 2026,
  "bill_month": 4
}
```

---

### N2 交租日提醒（rent_due_reminder）

**触发时机：** 每日 08:03 检查，提前 3/2/1 天各提醒一次

**通知内容：**
```
标题：交租日提醒 - {租客名}
内容：租客 {租客名}（房间 {房间号}）账单将在 {N} 天后到期，金额 ¥{总额}，截止日期 {日期}。
```

---

### N3 账单逾期（bill_overdue）

**触发时机：** 每日 08:05 检查，账单逾期后每日发送

**通知内容：**
```
标题：账单逾期提醒 - {租客名}
内容：租客 {租客名}（房间 {房间号}）账单已逾期 {N} 天。金额 ¥{总额}，截止日期 {日期}。
```

---

### N4 收款到账（payment_received）

**触发时机：** 租客付款成功（Payment 状态 → paid）后立即发送

**通知内容：**
```
标题：收款到账 - {租客名}
内容：租客 {租客名}（房间 {房间号}）已付款 ¥{金额}，支付方式 {方式}，付款日期 {日期}。
```

**extra_data 字段：**
```json
{
  "category": "billing",
  "target_path": "/bills",
  "action_label": "查看账单",
  "payment_id": "...",
  "bill_id": "...",
  "tenant_name": "...",
  "room_number": "...",
  "amount": 2000.00,
  "payment_method": "wechat"
}
```

---

### N5 租约即将到期（lease_expiring）

**触发时机：** 每日 08:00 检查，提前 7/3/1 天各提醒一次

**通知内容：**
```
标题：租约即将到期 - {租客名}
内容：租客 {租客名}（房间 {房间号}）租约将在 {N} 天后到期（{日期}），请及时处理续约或退房事宜。
```

---

### N6 租约已结束（lease_ended）

**触发时机：** 租约状态变为 `ended` 或 `terminated` 时立即发送

**通知内容：**
```
标题：租约{已结束/已终止} - {租客名}
内容：租客 {租客名}（房间 {房间号}）租约已于 {日期} {结束/终止}。
```

| 场景 | 租约状态 | 标题 |
|------|---------|------|
| 正常到期 | ended | 租约已结束 |
| 提前退租 | terminated | 租约已终止 |

---

### N7 水电读数异常（utility_reading_abnormal）

**触发时机：** 水电读数录入时，本期读数 < 上期读数

**通知内容：**
```
标题：水电读数异常 - {房间号}
内容：房间 {房间号} 的{水/电}表读数异常（本期 {读数} < 上期 {上期读数}），已暂停自动计算，请人工处理。
```

## 五、发送对象规则

通知仅发送给以下角色：

- **组织所有者**（is_system=true, name='组织所有者'）
- **公寓管理人**（is_system=true, name='公寓管理人'）

排除：一般合伙人、自定义角色（无账单管理权限者不通知）

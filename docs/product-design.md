# Apartment Ultra 产品设计与功能描述文档

## 一、产品概述

### 1.1 产品定位

Apartment Ultra 是一款面向房东和房产管理者的 **多租户 SaaS 公寓/房产管理系统**。系统支持管理多个租赁房产，涵盖公寓、房间、租客、租约、水电追踪、账单和经营分析等核心功能，并支持多用户团队协作。

### 1.2 目标用户

- 拥有多套出租房源的个人房东
- 小型房产管理公司
- 公寓运营商
- 物业管理团队

### 1.3 核心价值

- **统一管理**: 集中管理所有房产、租客和财务信息
- **自动化账单**: 自动生成月度账单，包含租金和水电费用
- **团队协作**: 支持多用户协作，权限分级管理
- **数据洞察**: 提供经营分析报表，辅助决策

#### 账单生成规则

1. 获取所有活跃租约
2. 检查该租约当月是否已有账单（避免重复）
3. 获取当月和上月水电读数
4. 计算各项费用：
   - 租金 = 租约约定的月租
   - 水费 = (当月水表读数 - 上月水表读数) × 水费单价
   - 电费 = (当月电表读数 - 上月电表读数) × 电费单价
5. 创建账单记录

## 五、安全设计

### 5.1 身份认证

- 基于 JWT 的身份认证机制
- Access Token + Refresh Token 双令牌设计
- 密码使用 bcrypt 加密存储

### 5.2 权限控制

- 基于角色的访问控制 (RBAC)
- 四级权限：owner / admin / member / viewer
- 每个请求验证用户对组织的访问权限

### 5.3 数据隔离

- 多租户架构，组织间数据完全隔离
- 所有业务查询自动过滤当前组织

## 二、缺陷清单

### 2.1 阻塞级缺陷 (P0)

| 缺陷编号 | 用例编号 | 缺陷描述 | 严重程度 | 状态 |
|---------|---------|---------|---------|------|
| BUG-E2E-001 | AUTH-LOGIN-01 | 业务端登录态 setup 失败：登录后无法跳转到仪表盘页面，测试期望找到"仪表盘"或"欢迎使用公寓管理系统"文本，但实际页面未显示这些文本 | P0 | 🔴 待修复 |

**详细描述**：
- 位置：`e2e/business.auth.setup.ts`
- 错误信息：`element(s) not found - expecting "仪表盘" or "欢迎使用公寓管理系统"`
- 影响范围：业务端所有需要登录态的 E2E 测试无法运行
- 根本原因：
  1. 测试代码期望找到"仪表盘"标题，但实际前端页面使用的是"首页"
  2. 前端代码 `dashboard-content.tsx` 中标题为"首页"（第 112 行），而非"仪表盘"
  3. "欢迎使用公寓管理系统"只在没有组织时显示（第 91 行），新注册用户有默认"个人"组织，不会显示此提示

**修复建议**：
1. 修改测试代码，将期望文本从"仪表盘"改为"首页"
2. 或统一前端文案，将"首页"改为"仪表盘"

## 六、附录

### 6.1 测试执行命令

```bash
# 运行业务端测试
pnpm exec playwright test business

# 运行运营端测试
pnpm exec playwright test admin

# 运行所有测试
pnpm run test:e2e

# 创建登录态
pnpm exec playwright test --project=business-setup
pnpm exec playwright test --project=admin-setup
```

### 6.2 测试文件位置

- 业务端测试：`e2e/business.spec.ts`
- 运营端测试：`e2e/admin.spec.ts`
- 业务端登录态：`e2e/business.auth.setup.ts`
- 运营端登录态：`e2e/admin.auth.setup.ts`

### 6.3 缺陷优先级定义

- **P0（阻塞）**：核心功能无法使用，阻塞测试进行
- **P1（严重）**：主要功能异常，影响用户体验
- **P2（一般）**：次要功能问题或 UI 问题

# 移动端设计规范

## 一、设计目标

为公寓管理系统设计移动端客户端，适配 H5（浏览器）和微信小程序。

---

## 二、屏幕适配

### 移动端视口
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
```

### 尺寸基准
- **设计稿宽度**: 375px (iPhone SE / 标准手机)
- **安全边距**: 16px (左右各留 16px)
- **微信小程序 rpx**: 750rpx = 375px

### 响应式断点
| 设备 | 宽度 |
|------|------|
| 小屏手机 | < 320px |
| 标准手机 | 320px - 375px |
| 大屏手机 | 376px - 414px |
| 平板竖屏 | >= 415px |

---

## 七、页面布局

┌────────────────────────┐
│ ← 返回    页面标题    │  ← 顶部导航 (44px + 状态栏)
├────────────────────────┤
│                        │
│      页面内容         │  ← 主体内容 (可滚动)
│                        │
│                        │

## 十、动效

### 过渡动画
- **页面切换**: 200ms ease-out
- **弹窗出现**: 300ms cubic-bezier(0.16, 1, 0.3, 1)
- **按钮点击**: scale(0.98), 100ms

### 手势反馈
- **列表项按下**: background #F1F5F9
- **卡片悬浮**: 不适用 (移动端)

## 十一、微信小程序特殊适配

### tabBar 配置
```json
{
  "tabBar": {
    "color": "#94A3B8",
    "selectedColor": "#2563EB",
    "backgroundColor": "#FFFFFF",
    "borderStyle": "white",
    "list": [
      { "pagePath": "pages/dashboard/index", "text": "首页" },
      { "pagePath": "pages/apartments/index", "text": "房源" },
      { "pagePath": "pages/tenants/index", "text": "客户" },
      { "pagePath": "pages/notifications/index", "text": "消息" },
      { "pagePath": "pages/settings/index", "text": "我的" }
    ]
  }
}
```

### 尺寸单位
- 使用 `rpx` 替代 `px`
- 公式: `rpx = px * (750 / 375)`

### 兼容处理
- 避免使用 `position: fixed` 配合 `calc()`
- 使用小程序原生组件: `picker`, `switch`, `checkbox`, `radio`

# UI 设计目录

本目录保存页面原型、历史设计稿与布局参考。

## 作用

- 帮助理解页面意图、信息结构与交互方向
- 为新页面设计或重构提供参考素材
- 保留历史方案，便于回溯设计演进

## 维护原则

- 设计稿不是当前代码实现的唯一真相。
- 如果设计稿与实现不一致，优先以代码和测试用例为准。
- 当某份设计稿明显过时但仍有历史价值时，建议保留并在目录索引中标记为“历史参考”。

## 目录说明

- `admin-system/`
  作用：运营后台页面原型。
- `apartment-system/`
  作用：租客端 / 公寓管理 Web 页面原型。
- `mobile/`
  作用：移动端页面草图与视觉参考。

## 建议使用方式

- 做新功能前，先看是否已有对应设计稿。
- 做重构时，用设计稿帮助识别原始产品意图。
- 不要把设计稿里的静态文本、按钮或路径直接当成当前实现状态。

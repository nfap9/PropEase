# 租客端使用指南

**访问地址：** 
生产部署时：http://server_location/tenant/
本地开发时：http://localhost:3000/tenant/

---

## 首次使用

### 1. 注册账号
1. 打开租客端页面
2. 输入手机号和密码
3. 点击「注册」或「登录」

### 2. 创建公寓
1. 进入「公寓管理」页面
2. 点击「添加公寓」
3. 填写公寓名称、地址等信息
4. 点击「保存」

---

## 日常管理流程

### 添加房间
1. 进入「房间管理」页面
2. 点击「添加房间」
3. 填写房间号、楼层、面积等
4. 点击「保存」

### 配置价格
1. 在房间列表中点击对应房间
2. 点击「价格配置」
3. 设置租金、水费基准、电费基准等
4. 点击「保存」

### 创建租约
1. 进入「租约管理」页面
2. 点击「新建租约」
3. 选择房间、填写租客信息（姓名、电话）
4. 设置租金、押金、租期等
5. 点击「保存」

### 录入水电
1. 进入「水电管理」页面
2. 点击「录入水电」
3. 选择房间、填写水表/电表读数
4. 点击「保存」

### 生成账单
1. 进入「账单管理」页面
2. 点击「生成账单」
3. 选择年月，确认生成
4. 系统自动计算租金 + 水电费

### 收款
1. 在账单列表点击对应账单
2. 查看账单详情（租金、押金、水电等明细）
3. 点击「收款」
4. 确认金额，选择支付方式
5. 点击「确认」完成收款

---

## 账单说明

生成的账单包含以下费用项：
- **租金**：月租金（来自租约配置）
- **押金**：首期账单显示（来自租约押金设置）
- **水费**：用水量 × 单价
- **电费**：用电量 × 单价
- **其他费用**：如有额外费用

---

## 常见问题

**Q: 为什么账单金额为 0？**  
A: 请先确认已配置房间价格、创建租约、录入水电。

**Q: 账单生成重复了？**  
A: 系统会跳过已有账单的月份，不会重复生成。

**Q: 如何查看历史账单？**  
A: 在账单列表中选择不同年月筛选即可。
